# B站清澈人声、音量增强与动态音量平衡

> **开发背景与 AI 声明**
>
> 由于本人在 B站观看视频时，比较依赖 B站官方的音频增强功能。2025 年的某个月，不知出于什么原因，这项功能从所有视频播放器中消失了。
>
> 在经历了一年多的等待后，目前依然没有再次用上这项功能，因此我决定借助 AI 编写一个功能相近的脚本。
>
> **以下介绍及脚本代码均由 AI 生成。**

这是一个面向 Bilibili 网页播放器的音频增强脚本，主要用于改善视频音量偏小、人声不够清楚，以及不同视频或不同说话者之间音量差异过大的问题。

所有音频处理均在浏览器本地通过 Web Audio API 完成，不会上传音频或收集播放记录。

## 主要功能

### 清澈人声

提供三种人声预设：

- **A 轻柔**：较自然、处理感较弱，适合已经比较清楚的人声。
- **B 原生**：按照 B站原生“清澈人声”的风格调校，兼顾清晰度与响度。
- **C 强化**：进一步突出人声存在感，适合录音偏闷或背景声较重的视频。

每次打开新视频时，清澈人声默认关闭，不会自动沿用上一个视频的选择。

### 音量增强

可在 **-12 dB 至 +12 dB** 范围内手动调节音量，步进为 0.5 dB。

适合整体录音音量偏小或偏大的视频。每次打开新视频时，手动音量增强会恢复为 0 dB。

#### 滚轮 / 方向键音量增强（最高 1000%，仅网页全屏 / 全屏）

滚轮调音量的默认开关是**开启**（可在油猴菜单的「滚轮/方向键调音量默认」中关闭，该选项会保存为默认配置，之后打开新视频同样生效）；除此之外，脚本只在播放器处于**网页全屏或全屏模式**时才接管滚轮和上下方向键。

两个前提都满足时，鼠标位于**播放器任意位置**（画面、覆盖层或控制栏）时，滚轮均可调节音量；上下方向键同样可以调音量（与 B站 原生按键位置一致），最高 **1000%**（约 +20 dB）。Ctrl / Command 加滚轮不会被脚本接管。

普通、宽屏、小窗等模式下脚本**完全不拦截事件**，也不阻止页面滚动，音量完全交给 B站播放器自己的逻辑处理（方向键则由 B站 与页面按原生方式处理）。模式判定依次为：浏览器全屏 API（`document.fullscreenElement` 等）→ B站播放器的 `data-screen` 属性（`web`=网页全屏、`full`=全屏）→ 播放器/页面类名兜底 → 播放器是否铺满视口兜底；如果以上都判断不出沉浸模式，按「不接管」处理。

- **0%–100%**：滚轮每次滚动增减 **1 个百分点**，上下方向键每次按键增减 **5 个百分点**，均由脚本直接调节视频音量。
- **100%–1000%**：向上滚动或按上键每次按 **1.1 倍**递增，向下按相同比例递减。降回 100% 后，继续向下即可调低普通音量，最低 0%。
- **静音时**：向上滚动或按上键从 0% 起步恢复声音（滚轮 +1%、方向键 +5%），并清除残留增幅。
- **长按方向键**：自动重复会限流（约每 90 ms 一档），避免音量或增强倍率瞬间被拉飞。

滚轮或方向键调节时，播放器中央显示半透明的「扬声器图标 + 当前百分比」提示，覆盖 0%–1000%。连续调节会刷新数值，停止约 1 秒后自动隐藏；支持全屏显示。

由于浏览器不允许 `video.volume` 超过 1.0，超出 100% 的部分通过音频处理链中的增益节点实现。B站原生音量滑块最多到 100%，脚本会尝试同步面板数字，当前增幅也会显示在播放器左上角状态栏「音量增强」和音频增强面板中。

「高增益防削波」**默认开启**，在增强超过 100% 时启用限幅器以减轻削波，可在油猴菜单中关闭；动态音量开启时由动态音量自己的限幅策略接管。已保存的用户开关选择会继续保留。

在音频增强面板里点击增幅数值可立即重置为 100%。每次打开新视频时，滚轮增强会重置为 100%。

### 动态音量平衡

脚本会持续检测当前响度，在 **-12 dB 至 +12 dB** 范围内自动补偿，尽量减小不同视频、不同说话者和不同片段之间的音量差异。

提供三档目标响度：

- **舒适：-16 LUFS**，适合长时间观看。
- **标准：-14 LUFS**，兼顾响度与舒适度。
- **响亮：-12 LUFS**，适合本身音量明显偏小的视频。

动态音量在首次安装时默认关闭。可以在油猴菜单中设置新视频默认开启或关闭，并选择默认目标响度。

> 说明：脚本用简化的 K-weighting 近似滤波（高架 + 高通）和 30–100 ms 的短块统计响度，显示的数值属于**近似 LUFS**，与专业响度计（ITU-R BS.1770）的读数可能存在 1 LU 左右偏差，仅作为自动补偿的相对参考。

## 五档响应速度

- **极速**：适合多人游戏语音、发言者频繁切换的内容。
- **快速**：适合多人对话、直播连麦和访谈。
- **均衡**：适合单人讲话但偶尔远离麦克风的内容，也是默认档位。
- **平缓**：适合教程录制、长时间解说等音量变化较少的内容。
- **慢速**：适合整体音源稳定、希望尽量减少处理感的内容。

响应越快，越能及时跟随短时间的音量变化；响应越慢，听感通常越平稳自然。建议先使用“均衡”，再根据视频类型调整。

## 使用方法

1. 打开任意 Bilibili 视频页面。
2. 播放器音量按钮左侧会出现两个功能按钮：
   - 音频增强：调节清澈人声和手动音量增强。
   - 动态音量：调节自动响度平衡、目标响度和响应速度。
3. 也可以在播放器画面上点击右键，从 B站原生右键菜单进入对应功能。
4. 把播放器切到**网页全屏或全屏**，鼠标停在播放器任意位置滚动滚轮，或按上下方向键，即可调节 0%–1000% 音量（滚轮每次 1%、方向键每次 5%），中央会显示当前百分比；普通、宽屏、小窗等模式下音量由 B站 原生逻辑处理。如果不想要脚本接管，可在油猴菜单中关闭「滚轮/方向键调音量默认」（默认开启）。
5. 油猴扩展菜单中可以设置滚轮/方向键调音量的默认开关、动态音量的默认状态、默认目标响度、五档响应速度、状态栏显示方式，以及高增益防削波开关。

## 实时状态栏

启用相关功能后，播放器左上角可以显示：

- 当前响度与动态补偿值。
- 当前动态响应档位。
- 手动音量增强的分贝数。
- 当前清澈人声预设。
- 音量增强超过 100% 时，显示当前倍率（如 `348%`）。

状态栏会跟随播放器控制栏一起显示或隐藏。可以在油猴菜单中关闭状态栏，或将背景不透明度设置为 25%、45%、65% 或 85%。

## 默认行为

- 新视频的手动音量增强默认为 **0 dB**。
- 新视频的清澈人声默认为 **关闭**。
- 动态音量默认关闭，但可以通过油猴菜单改为默认开启。
- 动态音量的目标响度和响应速度会保存到浏览器本地。
- 滚轮/方向键调音量默认 **开启**，但只在网页全屏/全屏模式下由脚本接管（滚轮每次 1%、方向键每次 5%）；可在油猴菜单中关闭，选择会保存到浏览器本地。
- 新视频的音量增幅恢复为 **100%**。
- 高增益防削波默认 **开启**；菜单中已保存的开关选择优先于默认值。

## 注意事项

- 请不要同时启用多个会接管 B站视频音频的油猴脚本，否则浏览器可能拒绝重复创建音频处理链。
- 如果提示视频已被其他音频脚本占用，请停用旧版或其他音频处理脚本，然后刷新页面。
- 浏览器可能要求先点击一次页面或开始播放，之后 Web Audio 音频处理才会启动。
- 动态音量无法单独分离已经混在一起的人声、音乐和游戏声音，它调节的是视频的整体响度。
- 极端增益可能同时放大底噪，建议优先尝试动态音量，再按需要增加手动增益。
- 本脚本为第三方用户脚本，与哔哩哔哩官方无关。
